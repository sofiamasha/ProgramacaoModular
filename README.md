# 🌸 Programação Modular

> Repositório destinado às atividades e estudos da disciplina de **Programação Modular**.

---

## 🎀 Sobre a disciplina

A disciplina de **Programação Modular** tem como objetivo desenvolver a capacidade de criar programas de forma organizada, estruturada e eficiente.

Durante a matéria, são trabalhados conceitos fundamentais de programação, buscando não apenas fazer o código funcionar, mas principalmente **entender a lógica por trás de cada solução**.

### 💗 Principais conteúdos

- 🧩 Modularização de programas
- 🔢 Variáveis e tipos de dados
- 🔁 Estruturas de repetição
- 🔀 Estruturas condicionais
- 📦 Vetores
- 🧮 Matrizes
- 🔤 Strings
- ⚙️ Funções e métodos
- 🔍 Manipulação e processamento de dados
- 🧠 Desenvolvimento de lógica de programação
- 💻 Implementação de algoritmos

---

## 🌷 Objetivo

O principal objetivo deste repositório é registrar minha evolução na disciplina, colocando em prática os conteúdos estudados através de exercícios e atividades.

A ideia é desenvolver os programas **entendendo a lógica utilizada**, e não apenas decorar códigos.
